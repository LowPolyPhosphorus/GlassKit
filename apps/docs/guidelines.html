Platform

Apple-inspired. Windows-first.

A short set of rules that keeps the visual craft high and the native behaviour intact.

Use real material

Apply native blur and rounded HWND corners instead of imitating them with CSS alone.

Keep colour in the content

Neutral glass should carry the surface; let app content provide emphasis.

Make motion meaningful

Use shared springs for state changes, and honour the Windows reduce-motion setting.

Stay accessible

Maintain keyboard focus, UI Automation support, and readable contrast in both themes.

Respect Windows

Preserve the taskbar, tray, right-click menus, shortcuts, and window snapping.

Avoid

Traffic lights, Mac gestures, Apple logos, SF Pro, SF Symbols, SetWindowRgn on transparent WebView2 windows, and focus handlers that clear and reapply material.
