# Glass Kit Docs

Astro documentation site for Glass Kit.

- `/` — product overview, tokens, materials, motion, component atlas, SwiftUI reference, and the interactive desktop lab.
- `/docs` — full developer manual with quick start, tokens, components, events, motion, native material, theming, generated API reference, recipes, troubleshooting, and release checklist.
- `/motion` — spring model, recipes, and live spring lab.
- `/native` — native material bridge, Tauri host, and Windows behaviour.
- `/practice` — design principles, typography, colour, writing, and release review questions.

The developer manual at `/docs` includes a registry-driven browser for all 128 components, searchable headings and tags, copyable markup, live previews, and a small event playground. All pages share one layout, one authored stylesheet, the preloaded Inter subset, and the global site script.
