Platform 06

Guidelines

Apple-inspired visuals. Windows-native behaviour.

Use

  • Real native blur and rounded HWND corners.
  • Neutral glass, with colour supplied by content.
  • Shared springs for open, close, and layout changes.
  • Reduced motion, keyboard focus, and UI Automation.
  • Taskbar, tray, right-click, snapping, and shortcuts.

Avoid

  • CSS backdrop-filter as the only material.
  • SetWindowRgn on transparent WebView2 windows.
  • Clearing and reapplying material on focus events.
  • SF Pro, SF Symbols, Apple logos, Mac gestures.
  • Colour blobs and oversized shadows as fake depth.
Glass Kit · Reference Visual inspiration only. No Apple assets or interactions.
