Glass Kit

A quieter way to build glass interfaces on Windows.

Tokens, native desktop material, shared spring physics, and framework-agnostic components — designed with Apple's clarity, deference, and depth, but built for Windows behaviour.

Clarity

Content stays legible. Colour supports meaning instead of decorating surfaces.

Deference

Glass frames the app; it never competes with the window or the desktop behind it.

Depth

Layers come from real material, translucency, and restrained elevation.

Native material

CSS backdrop-filter cannot sample the desktop through a transparent WebView2 window. GlassKit applies blur and rounded corners to the HWND, then layers neutral veils in the web content.

Best practices

Apple-inspired visuals. Windows-native behaviour.

01

Use real material

Apply native blur and rounded HWND corners instead of imitating them with CSS alone.

02

Keep colour in the content

Neutral glass should carry the surface; let app content provide emphasis.

03

Make motion meaningful

Use shared springs for state changes, and honour the Windows reduce-motion setting.

04

Stay accessible

Maintain keyboard focus, UI Automation support, and readable contrast in both themes.

05

Respect Windows

Preserve the taskbar, tray, right-click menus, shortcuts, and window snapping.

Avoid

Traffic lights, Mac gestures, Apple logos, SF Pro, SF Symbols, SetWindowRgn on transparent WebView2 windows, and focus handlers that clear and reapply material.

Glass Kit · Design system for Windows Visual inspiration only. No Apple assets or interactions.
