Why native?

A transparent WebView2 window has no desktop pixels for CSS backdrop-filter to sample. The real blur must be applied to the HWND. The browser preview shows the veil; the Native section applies the real material when this page runs inside a Tauri window.

06 / Guidelines

Design rules

Apple-inspired visuals. Windows-native behaviour.

HIG-informed

Do

  • Use real native blur and rounded HWND corners.
  • Keep glass neutral and let content provide colour.
  • Use shared springs for open, close, and layout changes.
  • Honour reduced motion, keyboard focus, and Windows UI Automation.
  • Keep taskbar, tray, right-click, snapping, and shortcuts native.

Don't

  • Don't use CSS backdrop-filter as the only material.
  • Don't use SetWindowRgn on transparent WebView2 windows.
  • Don't clear and reapply material on focus events.
  • Don't ship SF Pro, SF Symbols, Apple logos, or Mac gestures.
  • Don't fake depth with colour blobs or oversized shadows.
